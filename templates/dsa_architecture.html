1. Priority Queue (Min-Heap)

Implemented in dsa/priority_queue.py using a custom binary min-heap array.

Severity Ranks:
  • Critical Rank 1 (Top Priority)
  • High Rank 2
  • Medium Rank 3
  • Low Rank 4 (Lowest)
FIFO Tie-Breaking:

When two calls have identical severity, the heap compares the secondary key (arrival order / request_id), ensuring strict First-In, First-Out servicing.

Parent: (i - 1) // 2
Left Child: 2*i + 1
Right Child: 2*i + 2
Time Complexity: O(log N)

3. Dijkstra's Algorithm

Implemented in dsa/dijkstra.py to calculate the optimal real-world road route.

Mechanics:
  1. Initialize distance to start node as 0, all others ∞.
  2. Min-Heap stores (dist, vertex) pairs.
  3. Greedily extract the vertex with minimal tentative distance.
  4. Relax all adjacent outgoing road edges:
    if dist[u] + w < dist[v]: dist[v] = dist[u] + w
  5. Backtrack via predecessor map to yield the full path array.
Time: O((V + E) log V)
Space: O(V)
